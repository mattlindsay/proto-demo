1 Create the new file In Cursor's Explorer panel (the file icon at the top of the sidebar), right-click directly on the Github folder name at the top of the file list, and choose New File. 2 Name it index.html Cursor will show a text box for the filename. Type exactly index.html and press Return. It'll open as a new, empty tab. 3 Paste in the code and save Click inside the empty file, select all (⌘A) if anything's there, then paste the code block above (⌘V). Save with ⌘S — the small dot on the tab will disappear once it's saved. 4 Commit and push Click the Source Control icon (the same branching-line icon from before). You'll see index.html listed under Changes. Type a message like "Add index page" in the box, click Commit, then use the … menu or sync icon to Push. One thing worth knowing: naming it exactly index.html at the root of the repo isn't just a naming preference — if you turn on GitHub Pages later, that's specifically the file it looks for as the homepage. So this sets you up nicely for that next step whenever you're ready for it.
